# Bob-core material laboratory witness

This private F210 2.1.23 fixture is for the exact no-Angel Bob-core closure
captured in `bob-core-f210-captured-facts.json`. Before it accelerates anything,
its data-final stage checks the independent identities, ordered prerequisites,
ordered science vectors, default cost and time, finite/tail boundary,
presentation flags, and recipe-productivity effect for all fourteen selected
technologies: Tin, Lead, Bronze, Gunmetal, Invar, Nitinol and Copper Tungsten.
It then changes only each selected research unit to one count and one second.

On a new disposable world it marks only the explicit non-MIR prerequisites as
researched, inserts the six independently named science packs into a real lab,
and earns three finite levels plus one continuation level for every family. It
requires 28 native `on_research_finished` events, exact 28/20/16/8/10/4 input
consumption (automation/logistic/chemical/production/space/metallurgic), and a
native 8% bonus on every named route. It saves after completion; the native
runner must perform two cold reloads, where the fixture only reads the saved
witness.

The fixture does not manufacture science, alter ordinary material tuning, seed
selected MIR levels/effects/queues, inspect MIR private state, or make a
foreign-force preservation claim. A current candidate full-catalogue capture
and comparison remains required before native qualification or dispatch.

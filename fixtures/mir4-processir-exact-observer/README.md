# MIR 4 exact ProcessIR observer

This package-excluded fixture is materialized dynamically for T12 exact target captures. It depends on the exact MIR candidate and executes after the terminal compiler in `data-final-fixes`. It serializes a deterministic bounded selection from the terminal `recipe_facts`, `recipe_risk_facts`, relationship and CompilationSnapshot authorities.

The observer has no prototype writes, runtime control stage, network path, support-claim authority, planner/emitter admission, signing, sealing or publication authority. When Factorio cannot expose a trustworthy recipe last-writer, the record says `unavailable` rather than inventing an owner.

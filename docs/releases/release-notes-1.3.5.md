# MIR 1.3.5 Factorio 0.13 Local Candidate Record

MIR 1.3.5 is the Factorio 0.13 finite-substitute projection of the MIR 3.2.5 unified research-cost slice on canonical lower-wave anchor `6ac377389d7ffc3576fb39576dab4ace6efaec51`.

It compiles the shared cost model into positive bounded first-continuation counts. Factorio 0.13 cannot represent native infinite formulas, so curve-selection controls and later continuation levels are deliberately omitted. It also excludes Factorio 0.14+, modern science names, recipe productivity, DLC, settings profiles, and generalized compatibility-platform features.

Local binary qualification may prove the target projection while remote services are unavailable, but it does not create release authority. Tag and `dist/` promotion remain blocked until the immutable 3.2.5 lineage exists.

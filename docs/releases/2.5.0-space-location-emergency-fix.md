# MIR 2.5.0 Space-Location Discovery Emergency Fix

## Release blocker

MIR 3.2.0's generic technology-effect sanitation resolved `unlock-space-location` targets only from the abstract `space-location` prototype bucket. Factorio stores concrete planets in the separate `planet` prototype bucket even though a planet is a space location. Valid researched planet-discovery effects were therefore classified as missing and removed.

The player-visible result was severe:

- researched Space Age planets disappeared from the normal starmap;
- space connections became unavailable;
- platforms refused to travel to planets reported as undiscovered;
- the planet surfaces still existed and were reachable through editor or alert shortcuts;
- disabling MIR restored access because the valid discovery effects were no longer removed.

## Correction

The canonical SpaceLocationID resolver now includes both:

```text
space-location
planet
```

The same canonical type list is used for input capture and final inventory parity checks. Recipe, item, quality, entity, ammunition, and other target sanitation behavior is unchanged.

No global `reset_technology_effects()` call was reintroduced. MIR continues to avoid broad force-state reapplication and the associated risk to unrelated external effects.

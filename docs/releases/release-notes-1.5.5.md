# MIR 1.5.5 Factorio 0.15 Local Candidate Record

MIR 1.5.5 is the Factorio 0.15 target-native projection of the MIR 3.2.5 unified research-cost slice on canonical lower-wave anchor `dc5bfa99249af6c9508201a4c4667063bc8e021c`.

It retains the reduced native-infinite technology set and adds fixed, linear, exponential, and hybrid continuation costs. It does not import Factorio 0.16+, modern science names, recipe productivity, DLC, settings-profile, or generalized compatibility-platform features.

Local binary qualification may prove the target projection while remote services are unavailable, but it does not create release authority. Tag and `dist/` promotion remain blocked until the immutable 3.2.5 lineage exists.

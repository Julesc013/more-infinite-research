# MIR 3.2.5 Convergence Release

MIR 3.2.5 is the only planned public Factorio 2.1 release after 3.2.3. It combines C31's unreleased research-cost work with compatibility dispositions, proof-derived claims, exact environment identities, bounded support reporting, and the behavior-preserving internal consolidation needed to support them.

## Public contract

- Existing technology, setting, locale, runtime, and profile identifiers remain stable.
- New settings use neutral defaults.
- Default behavior remains equivalent to 3.2.3 except for named, evidence-backed compatibility corrections.
- Old profiles remain readable and unknown future fields remain preserved.
- The public upgrade path is 3.2.3 to 3.2.5.
- Breaking compiler and extension-platform changes remain 3.3 work.

## Research costs

Every MIR-owned or explicitly supported native-owner research uses the canonical contract:

```text
cost(L) = (B + A * (L - S)) * G ^ (L - S)
```

The numeric parameters derive fixed, linear, exponential, and hybrid behavior. There is no redundant model selector. Unknown external formulas are preserved when no override is requested and reject an explicit override safely rather than being guessed.

## Compatibility explanations

The release derives subject-level planned, applied, and realized dispositions from the existing catalog, compiler result, transformation plan, mutation journal, and final state. Reporting is a read model and has no mutation authority.

Machine reports use stable outcome and reason codes. Human reports are localized and answer what happened, why, which authority decided it, whether it is safe, which setting may change it, and which proof supports it.

## Proof and environments

Public compatibility text remains derived from the existing maturity, behavior, and scope taxonomy plus typed proof assertions. Exact environment locks bind the Factorio binary and data, complete mod closure and hashes, startup settings, load order, target adapters, and assertion definitions.

## Privacy and resource safety

Support exports omit personal identity by default, redact paths and tokens, use deterministic allowlisted content, and enforce encoded bytes, decoded bytes, depth, cardinality, selector, string, row, and report-size limits. MIR does not upload reports or require telemetry.

## Factorio 2.0 projection

Every product slice declares whether it is portable unchanged, portable with an adapter, omitted, replaced on the target, tooling-only, or unsupported. The immutable 3.2.5 semantics are projected to 2.5.5 only after deterministic reconstruction and independent Factorio 2.0 qualification. A real reporting adapter is required because the 2.0 target lacks mod-data transport.

## Release gates

The release requires exact 3.2.3 upgrade proof, cost-model realization, disposition parity, compatibility environments, configuration recovery, privacy and localization review, paired performance, deterministic packaging, protected qualification, sealing, publication, and public-byte verification.

## Projection decisions

- Retain the C21 concrete `planet` and `space-location` resolver correction already present on the 2.0 line.
- Port the C24 hidden optional `pypostprocessing` ordering edge.
- Port the Py stale-unlock fixture through a Factorio 2.0 adapter and require an independent exact 2.0 Py closure.
- Omit the 3.2.0/3.2.1-to-3.2.2 runtime planet-recovery handler because no released 2.x package created that damaged state.
- Retain Factorio 2.0 target profiles, dependencies, capability cuts, fixtures, and independently generated evidence.
- Never reuse Factorio 2.1 evidence as Factorio 2.0 release evidence.

The exact portable-delta authority is `.mir/backport-portable-delta-3.2.2-to-2.5.0.json`; the source and package comparison is `.mir/backport-source-lock.json`.

## Player-visible 3.2.3 changes

### Platform Productivity

- Removed `ice-platform` and `space-platform-foundation` from Landfill Productivity ownership.
- Added a stable `research_platform` generated stream and technology identity.
- Applied `+10%` productivity per level to `ice-platform`.
- Applied `+5%` productivity per level to `space-platform-foundation`.
- Reused Landfill Productivity progression rules with `cryogenic-science-pack` replacing `metallurgic-science-pack`.
- Added the new Platform setting, locale key, stream manifest row, stable generated ID, and catalog assertions.
- Added `cryogenic-science-pack` to Ice Productivity so Aquilo-specific ice bonuses cannot be researched from Nauvis progression alone.

### Structural logistics productivity

- Added entity-aware structural recipe discovery for transport belts, underground belts, splitters, lane splitters, loaders, and inserters.
- Added a conservative `+0.5%` Belt Productivity fallback for structurally discovered modded logistics recipes.
- Added a conservative `+1%` inserter fallback for structurally discovered modded inserters.
- Preserved reviewed family precedence: explicitly reviewed logistics families replace fallback ownership instead of receiving duplicate or weaker effects.
- Preserved recipe-level productivity denials, including returned cryogenic-fluid outputs marked as productivity ignored.
- Added blanket discovery that does not depend on a third-party mod's recipe names or tier names.

### Bounded compiler optimization

- Added one immutable per-compilation entity-name/type, placeable-item/type, and module-tier index.
- Reused one stream-match result for unlock-derived science and emitted effect planning under an exact descriptor, recipe-fact, and target-profile identity.
- Replaced repeated fallback list reconstruction with set-based family override resolution and one sorted boundary materialization.
- Added governed work-volume assertions for one item-fact index build, one recipe-fact scan, at most one computation per stream-match identity, and zero duplicate owners.
- Added exact scale and randomized-order runtime scenarios to prove the optimization is behavior-preserving.

### Advanced Belts coverage

- Added an exact compatibility claim and support lane for `AdvancedBeltsSA`.
- Added assertion fixtures covering the three post-Turbo belt tiers, underground belts, and splitters.
- Added a governed test-only Factorio-line adapter that changes only the third-party archive's declared Factorio version and proves all other payload bytes unchanged.
- Verified all expected MIR productivity effects and returned-fluid denial contracts during Factorio 2.1 data-stage execution.
- Recorded the upstream limitation honestly: the current AdvancedBeltsSA archive targets Factorio 2.0 and later fails Factorio 2.1 recipe-schema validation for its own `category`/`additional_categories` fields. Exact 2.0 and 1.1 binary qualification remains target-line work.

### Metadata and presentation

- Advanced `info.json` and the changelog to 3.2.3.
- Added player release notes and the exact immutable candidate identity block.
- Updated all 50 shipped locale files and 49 translation-memory authorities for Platform Productivity.
- Retained the 3.2.2 stable identities and added one new stable generated stream identity.

### Exact save transition

- Added an exact tagged 3.2.2 to frozen-candidate Space Age save-upgrade fixture; it passed on C29 and is selected for an exact C30 rerun.
- Proved Landfill and Ice levels, current Ice research, 42% fractional progress, and startup settings survive.

- Persisted the C29 predecessor upgraded game to a separate governed save and independently reloaded it; exact C30 repetition remains required.

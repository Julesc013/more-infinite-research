# MIR 2.5.5 P12 Playtest Guide

Use only the exact candidate whose archive SHA-256 is `03DFC05F94435FAACB86F19D1BF0BCD160C515C46B8372C483EEBAEB5208A41C`.

1. Load a clean Base game under Factorio 2.0.77.
2. Load a clean Space Age game and inspect native productivity owners.
3. Exercise fixed, linear, exponential, and hybrid cost settings.
4. Upgrade a copy of a 2.5.0 save with an active infinite research.
5. Confirm technology level, current research, queue, and completed science-unit work survive.
6. Save, reload, and reload a second time to check idempotence.
7. Retain logs and before/after saves with the exact ZIP digest.

MIR 2.5.5 intentionally emits its bounded support record to the log and does not emit MIR `mod-data` on the Factorio 2.0 target.

## Risk contract

Default enablement and risk classification are independent dimensions. A technology can be enabled by default while retaining a stable risk class and reason. Risk-classified technology settings sort before ordinary technology settings, and MIR appends the localized warning to both the enable-setting tooltip and emitted technology tooltip unless that locale key is already present.

The current factory-disruptive rows are:

| Technology | Stable reason | Review focus |
| --- | --- | --- |
| Spoilage preservation | `existing-spoilable-stack-deadlines` | Existing stack timing, spoilage deadlines, factory throughput, and blueprint assumptions |
| Inserter capacity bonus | `inserter-hand-stack-and-circuit-behavior` | Hand-stack size, circuit-controlled inserters, blueprint behavior, throughput, and UPS-sensitive designs |

Future risky technologies should declare the same explicit classifier record rather than being inferred from a disabled default.

Use the exact ZIP above with a disposable save first.

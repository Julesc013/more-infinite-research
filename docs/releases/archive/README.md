# Release Archive

This directory preserves historical MIR release plans, qualification reports, publication receipts, old Mod Portal descriptions, and completed checklists. These files explain prior decisions and exact evidence; they are not current planning or public-copy authority.

Use the [release index](../README.md) for published versions, the [universal Mod Portal page](../mod-portal-page.md) for the sole current public description, and the [MIR 3 terminal `.9` programme](../mir-3-terminal-dot-9-programme.md) for current planning.

Archived files must retain truthful identities and name a current replacement. Do not revive a historical candidate, exception, tag instruction, or release train by editing its archive record.

## Bounded correction

Every successful competing-technology removal now records an exact fingerprinted journal row containing the removed graph node, replacement identities, and every dependent prerequisite before and after rewiring. The normal unchanged-graph path still reuses its qualified authority without rebuilding or rehashing the graph. A changed graph can pass only when the frozen journal projects the virtual snapshot to the exact realized snapshot and a fresh realized-graph qualification accepts every planned MIR technology.

The competing-productivity preparation pass now keeps its context-owned replacement table distinct from its per-technology eligibility boolean. Scenario manifests name the real competitor and assertion fixtures, and nested manifest settings are converted to hashtables before worker invocation.

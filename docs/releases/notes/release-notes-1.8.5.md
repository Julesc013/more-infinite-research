# MIR 1.8.5

MIR 1.8.5 is the frozen MIR 3 `.5` compatibility projection for Factorio 1.0.0 only. It follows MIR 1.8.2 and does not claim Factorio 0.18 support.

The exact GitHub asset is publicly verified with archive SHA-256 `10BA1F1D0EFDED559F447A05164E8865EE35F527C0A7D65D6CB7B1F8C1C4C1CD`. Automated target qualification and the downloaded public-asset startup load passed. No personal visual playtest is claimed.

All later corrections route to MIR 1.8.9; versions 1.8.6 through 1.8.8 are prohibited.

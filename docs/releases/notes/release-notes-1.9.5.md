# MIR 1.9.5

MIR 1.9.5 is the frozen MIR 3 `.5` compatibility projection for Factorio 1.1.110. It follows MIR 1.9.4 and retains the reduced Factorio 1.1 feature contract rather than claiming parity with Factorio 2.x.

The exact GitHub asset is publicly verified with archive SHA-256 `9F044A476500CB72A0C6A9A6254CC702E6621B2CDAEDA04A1188579ADF4AADCC`. Automated target qualification and the downloaded public-asset startup load passed. No personal visual playtest is claimed.

All later corrections route to MIR 1.9.9; versions 1.9.6 through 1.9.8 are prohibited.

## Hosted integration status

At audited `dev` commit `1af927d964f3386ff357fa3e292cd2f1af5fcfe0`, Branch Policy and MIR Emergency Package passed, while the MIR workflow failed before matrix execution because verification-plan materialization treated `candidate_id: not-assigned` as an invalid frozen candidate. `CHG-2026-0016` separates source-bound planning authority from strict candidate authority and makes the fast workflow build and transfer one byte-bound development archive before planning. A valid planned reservation may therefore materialize a plan against exact development bytes, while sealing and all candidate-bound release operations still require an assigned candidate and frozen package identity. This source repair requires a fresh hosted run before G0 can claim hosted closure.

## Cost-transition development evidence

The named `space-age-native-owner-settings-config-change` scenario passed on Factorio 2.1 after source-side checks, deterministic development packaging, fixture setup, configuration change, and log evaluation. The observed progress conversion was `0.10885649918078` at realized old cost `7593` to `0.028213660509272` at realized new cost `29296`. The same fixture exercised all sixteen fixed, linear, exponential, and hybrid descriptor transitions plus tampered-digest and over-budget refusal.

This proof is useful development evidence, but it is not candidate-bound or protected release evidence. The source and package must be rebuilt and the scenario rerun after every package-visible change.

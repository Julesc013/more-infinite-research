## Cost-transition development evidence

The named `space-age-native-owner-settings-config-change` scenario passed on Factorio 2.1 after source-side checks, deterministic development packaging, fixture setup, configuration change, and log evaluation. The observed progress conversion was `0.10885649918078` at realized old cost `7593` to `0.028213660509272` at realized new cost `29296`. The same fixture exercised all sixteen fixed, linear, exponential, and hybrid descriptor transitions plus tampered-digest and over-budget refusal.

This proof is useful development evidence, but it is not candidate-bound or protected release evidence. The source and package must be rebuilt and the scenario rerun after every package-visible change.

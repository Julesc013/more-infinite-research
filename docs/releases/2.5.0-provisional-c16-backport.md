# MIR 2.5.0 Provisional C16 Backport

MIR 2.5.0 candidate `2.5-P2` is an automated playtest candidate for Factorio 2.0. It is not release-qualified, sealed, tagged, published, or approved by manual review.

The projection is reconstructed from the immutable 2.4.9 history. C16 is a separate portable-source authority and is deliberately not merged into the target branch. This preserves Factorio 2.0 history while making the semantic source explicit.

## Exact Target Adaptation

The projected package differs from C16 in exactly four paths:

- `README.md` supplies Factorio 2.0 player guidance.
- `changelog.txt` identifies the provisional 2.5 line.
- `info.json` declares MIR 2.5.0 and Factorio 2.0 dependency floors.
- `prototypes/mir/platform/factorio/target_profiles.lua` projects the repository-owned Factorio 2.0 capability profile.

All other packaged paths are byte-for-byte portable projections of C16 after normalized text comparison. The Factorio 2.0 profile uses `tool` science prototypes, omits `mod-data`, disables productivity-family adoption, excludes the two Factorio 2.1-only cargo modifiers, and expects 71 streams.

The C16 trusted-record performance correction is included without changing technology identities, recipe membership, science, prerequisites, costs, effects, ownership, settings, locales, migrations, defaults, or promotion state. Effect-target sanitation is also included, so technologies whose recipes are removed by an overhaul are cleaned instead of retaining dangling recipe effects; the Py `casting-gear` removal report is covered by that contract and still requires exact Factorio 2.0 ecosystem validation.

## Upgrade Contract

The release-blocking predecessor is `2.4.9 → 2.5.0`. The older `2.4.5 → 2.5.0` row is retained as an additional non-blocking oldest-maintained upgrade check. Qualification must never substitute the older row for the immediate published predecessor.

## Current Gate

Target-profile static validation and deterministic packaging have passed. Exact Factorio 2.0 runtime, upgrade, ecosystem, paired-performance, approved-delta, complete no-reuse, and aggregate evidence remain candidate-bound work. Manual review and protected qualification remain pending by design.

Promotion to `legacy`, a `2.5.0` tag, a manual attestation, a schema-4 seal, or publication is prohibited until the exact final bytes pass those gates.

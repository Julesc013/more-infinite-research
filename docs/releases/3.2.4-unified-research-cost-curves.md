# MIR 3.2.4 Unified Research Cost Curves

> C31 is an immutable, superseded-unpublished candidate. Its work is development lineage for MIR 3.2.5; this document is not a public release plan.

MIR 3.2.4 gives every generated stream, vanilla continuation, and supported native-owner technology one cost contract:

```text
cost(L) = (B + A * (L - S)) * G ^ (L - S)
```

`S` is the first level controlled by the technology, `B` is its first-level cost, `A` is a non-negative additive increment per level, and `G` is an exponential multiplier of at least one. The implementation derives fixed, linear, exponential, and hybrid behavior from the numeric parameters; there is no model dropdown.

The existing base and growth setting IDs remain stable. The release adds `ips-cost-linear-increment-<stream>` and `mir-cost-linear-increment-<extension>`, both defaulting to zero. With that default, existing MIR curves retain their prior behavior. The player-facing label for the existing growth setting becomes “exponential multiplier” without renaming its stable ID.

Native and modded formulas use a bounded arithmetic classifier. Supported fixed, linear, exponential, and hybrid formulas can be overridden and are then emitted canonically. With no override, the original external formula is retained byte-for-byte. Unknown formulas are preserved at default settings and reject an explicit cost override rather than guessing.

## Release boundary

This release includes the cost-model vertical slice, stable settings, localization, focused fixtures, exact upgrade behavior, deterministic packaging, affected runtime qualification, approved delta, performance measurement, manual review, protected qualification, sealing, and promotion. It does not include the 3.2.5 StreamDisposition work or the broader 3.3/2.6 semantic-platform redesign.

The Factorio 2.0 line remains immutable at released 2.5.0/P11 during stabilization. A package-visible 2.5.1 is created only for a reproduced player-package defect; otherwise the target projection of this feature is deferred to 2.6.

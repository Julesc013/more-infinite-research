# MIR 2.5.0 Verification Backport Contract

Candidate 2.5-P11 retains literal ancestry from published MIR 2.4.9 commit 7ebe93029695bbf809a15a14c6540530738a9e62 and from tagged MIR 3.2.3 through portable C30 package source c1fd8b932c8d916a14925678056e08893b87b2db. The Factorio 2.0 package source is 493e71a6c883c2e191e1e13c7647cf38a8a8b261 and its exact archive SHA-256 is 65C1610BAE120F135E328583899672E3636EAAD6D946DF104FD045B2D9AB10F1.

The source lock compares the C30 and P11 package trees directly and requires exactly eight adapted paths. The dual-parent integration preserves both the target first-parent lineage and the tagged canonical source lineage. The portable-delta ledger classifies every C21, C24, C30, and P11 target-profile surface as retained, adapted, independently re-proven, target-incompatible, or version-specific and omitted.

Every target fingerprint is independent: package, Factorio 2.0.77 binary, target profile, fixtures, dependency closure, scenarios, approved delta, upgrades, performance, manual review, protected qualification, and seal. Factorio 2.1 evidence is design input only, including the time-boxed 3.2.3 publication record.

Release requires deterministic reconstruction, exact Base and Space Age loads, the full target scenario catalog, native AdvancedBeltsSA, exact 2.4.9 upgrade and approved delta, exact 2.0 Py finalizer repair, paired performance, maintained ecosystems, manual attestation, protected fresh qualification, seal verification, fast-forward promotion to legacy, and publication of the sealed ZIP without rebuilding.

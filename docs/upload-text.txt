GitHub prerelease: MIR 5.0.4

No Mod Portal upload is authorized for this prerelease. The maintainer handles Portal publication of qualified stable packages, using the identical tested GitHub ZIPs.

Changes: preserve earned weapon, electric/Tesla and sulfur bonuses when compatible native research takes ownership; avoid redundant future upgrades; handle invalid research events safely.

Modern engine inputs: Factorio 2.0.77 and 2.1.23. Library interaction/client and whole-product performance acceptance remain open. Factorio 0.18.47 and early builds remain experimental/best effort.

Early 0.6–0.12 ZIPs require extraction into the game's mods folder and contain a fixed finite subset without runtime features, settings, Library UI or migrations; they are not natively qualified. Factorio 0.18.47 is experimental/best effort; its native startup/crash smoke remains unverified. Provider changes with unmet prerequisites remain unqualified; retain the original save/mod selection.

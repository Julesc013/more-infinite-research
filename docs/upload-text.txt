GitHub prerelease: MIR 5.0.7

The maintainer handles Mod Portal publication of qualified stable packages, using the identical tested GitHub ZIPs. This prerelease is GitHub-only.

Changes: preserve affected earned Base research from MIR 1.0–1.2; preserve MIR 1.1 module bonuses when disabled on the first update; correct the MIR 4.7.3 Base upgrade check from Factorio 2.0.77 to 2.1.23; simplify contributor/support documentation.

Modern engine minima: Factorio 2.0.77 and 2.1.23. Focused published MIR 1.0/1.1/1.2/4.7.3 Base upgrade cases check earned bonuses, partial research, foreign state, new gear research, effects reset, save and cold reloads. Full historical/modpack coverage and arbitrary scripted bonus offsets remain unqualified. Real Industrial Chemistry runtime/save compatibility is unverified: 0.35.8 fails upstream on 2.1.23 without MIR; 0.36.1 has not been natively checked.

Full Library interaction/client acceptance, historical reconciliation and whole-product performance remain open. Provider changes with unmet prerequisites remain unqualified; retain the original save/mod selection. Factorio 0.18.47 and early builds remain experimental/best effort. Early 0.6–0.12 ZIPs require extraction and contain a fixed finite subset without runtime, settings, Library UI or migrations; native qualification is absent.

MIR 5 brings retained research and settings into one shared implementation, with edition-specific engine adapters, deterministic research generation and bounded scripted effects.

- Preserve established technology and setting identities, native bonuses, research progression and applicable historical capabilities.
- Add full and compact MIRSET1 settings exports to the modern Library, including selectable text and file output through the existing exporter.
- Add a bounded latest diagnostic report, written locally on request. Factorio's session log remains separate; no automatic upload occurs.
- Correct named compatibility bindings and migration ownership boundaries, including private credit research presentation. Retained credit stays separate from ordinary Library actions.
- Provide the documented modern MIR API 1.0 subset for immediate data-stage declarations and detached runtime inspection. Check its declared capabilities before using it.
- Keep complete source-version changelog history and extended GitHub edition numbers.

Choose the ZIP for your Factorio family. The nine stable-edition minimums are 0.13.20, 0.14.23, 0.15.40, 0.16.51, 0.17.79, 1.0.0, 1.1.110, 2.0.77 and 2.1.23. Each edition retains its actual supported subset; modern expansion research requires the relevant official mods.

F018 requires 0.18.47 and is GitHub-only experimental, with exact-engine native loading still unverified. The seven F006–F012 packages are best-effort finite, data-only historical builds without current native/save qualification; F006–F008 require extraction. F001–F005 have no deliverable. These additional builds do not extend stable-edition support.

Preserve the original save, matching mods and startup settings before upgrading. Test a copy, inspect earned research and bonuses, save under a new name and cold-reload before adopting it. Read the [support and upgrade guide](https://github.com/Julesc013/more-infinite-research/blob/v5.0.0/docs/support.md), especially the separate productivity-provider/preference transition and historical 4.2.1 recovery limits. A MIR settings profile does not back up other mods, map settings or research.

Edition packages retain versions such as 5.0.21000 for source 5.0.0. GitHub marks prerelease or stable separately from that version and the canonical tag. Prereleases remain GitHub-only; stable Portal releases use the identical tested ZIPs for the nine supported editions. Mod Portal availability is maintained separately.

Performance observations are specific to their tested engines, packages and workloads. Earlier accepted startup and active repair/agriculture comparisons are retained in the support guide; they do not establish universal speed, memory or compatibility gains for these final bytes.

Stable publication remains blocked on the recorded acceptance gates, final performance/applicability verdict, actual release date and artifact freeze. The authorized first `v5.0.0` GitHub prerelease may instead state explicitly unfinished performance tests as unverified, while retaining package integrity, exact source/package/controller provenance, upgrade-safety gates and every actual completed, failed and unverified result. This draft is preparation, not an announcement that stable acceptance has passed.

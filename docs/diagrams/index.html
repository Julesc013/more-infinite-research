MORE INFINITE RESEARCH / ARCHITECTURE ATLAS

Explicit research.
Deterministic construction.
Native execution.

Start with the whole-mod view, then trace one boundary at a time. The Generator creates native research during prototype loading. It does not run during gameplay, infer arbitrary research or manage saved worlds.

10 / How do we catch mistakes without rerunning everything?

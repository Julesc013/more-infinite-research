# Target boundary

The [target specification](../spec/targets.md) lists the nine stable editions and their qualification limits. [editions.json](editions.json) selects private source composition, native capability metadata and patch floors for those editions plus the separately labelled F018 experimental build. Exact MIR5 native and save qualification remains pending for the historical stable editions and F200.

Add only actual differences in metadata, syntax, native effects or runtime interfaces. Keep shared research source singular. Select one applicable adapter per self-contained player package. Tooling may use a modern host without restricting the target Factorio engine. Existing target version encoding is preserved unless separately reviewed.

The reduced adapter uses the shared eleven native-effect declarations and preserves the observed direct Base subsets: 7/7/9/10/11/11/11/11 technologies for F013/F014/F015/F016/F017/F018/F100/F110, plus2/2/4/4/5/6/5/6 applicable native continuations after the accepted F018 source integration; the F100 laser forward-continuity correction remains pending. Settings, science, prerequisites, icons, costs and finite limits follow actual target contracts. The portable historical native-state fixtures characterize earlier MIR4 behavior; retained historical 4.7 candidate ZIPs do not establish a published or qualified MIR5 output.

F200 shares the modern implementation while selecting native `probability`, retaining the `ignored_by_stats` productivity default, and excluding two unavailable cargo research modifiers and their settings. Its 875 setting descriptors match the retained 4.7 F200 archive in both Base and Space Age source-stage comparison. Its engine has fixed effect-receiver limits: selected receiver-limit overrides report that native restriction without writing unsupported fields. Native overrides, complete catalogue output, UI/runtime and save upgrades still require exact-engine qualification.

`tools/package.py --target f015` selects the reduced stage adapters, their actual Lua import closure and target metadata, and derives `5.0.01500` from source `5.0.21000`. A committed build binds the edition record at the same revision as player source. Source-only composition checks do not establish gameplay, upgrades or a release claim.

The canonical cutover is complete: this is `targets/`, selecting capability metadata rather than alternate editable player trees.

All extras need explicit best-effort release labels.

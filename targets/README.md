# Target boundary

The [target specification](../spec/targets.md) lists the inherited nine-edition baseline and its qualification limits. [editions.json](editions.json) selects private source composition, native capability metadata and baseline patch floors for all nine editions. Exact MIR5 native and save qualification remains pending for the historical editions and F200.

Add only actual differences in metadata, syntax, native effects or runtime interfaces. Keep shared research source singular. Select one applicable adapter per self-contained player package. Tooling may use a modern host without restricting the target Factorio engine. Existing target version encoding is preserved unless separately reviewed.

The reduced adapter uses the shared eleven native-effect declarations and preserves the observed direct Base subsets: 7/7/9/10/11/11/11 technologies for F013/F014/F015/F016/F017/F100/F110, plus 2/2/4/4/5/5/6 applicable native continuations. Settings, science, prerequisites, icons, costs and finite limits follow actual target contracts. The portable historical native-state fixtures characterize earlier MIR4 behavior; retained historical 4.7 candidate ZIPs do not establish a published or qualified MIR5 output.

F200 shares the modern implementation while selecting native `probability`, retaining the `ignored_by_stats` productivity default, and excluding two unavailable cargo research modifiers and their settings. Its 875 setting descriptors match the retained 4.7 F200 archive in both Base and Space Age source-stage comparison. Its engine has fixed effect-receiver limits: selected receiver-limit overrides report that native restriction without writing unsupported fields. Native overrides, complete catalogue output, UI/runtime and save upgrades still require exact-engine qualification.

`tools/package.py --target f015` selects the reduced stage adapters, their actual Lua import closure and target metadata, and derives `5.0.01500` from source `5.0.21000`. A committed build binds the edition record at the same revision as player source. Source-only composition checks do not establish gameplay, upgrades or a release claim.

The canonical cutover is complete: this is `targets/`, selecting capability metadata rather than alternate editable player trees.

[early-editions.json](early-editions.json) is a separate opt-in composition record for best-effort F006–F012. Use `python tools/package.py --source source --revision <full-commit> --target f006 --target-record targets/early-editions.json --output more-infinite-research_5.0.00600.zip` with a new output path. These editions emit14/22/22/22/22/22/26 finite default rows respectively and omit startup settings, runtime/API, Library and migrations. F006–F008 archives require extraction into the engine's mod folder; their direct ZIP loading is unproven. F009–F012 ZIP eligibility is source-evidenced but still lacks current native qualification. All extras need explicit best-effort release labels. F001–F005 and the previously excluded F018 remain unresolved under the [additional-edition contract](../spec/targets.md#additional-historical-editions); the nine-edition freeze does not claim them.
